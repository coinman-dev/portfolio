# Файлы, папки и логи

Программа хранит всё рядом со своим исполняемым файлом. В системном реестре
и в домашней папке пользователя ничего нет.

| Путь | Что там |
|---|---|
| `data/base/*.json` | Базы портфелей; по умолчанию открывается `default.json` |
| `data/settings.json` | Настройки программы и модулей, в том числе API-ключи CoinMarketCap и NEAR Intents |
| `data/cache.json` | Сохранённые цены и каталог монет |
| `data/wallets.json` | Сохранённые кошельки и сеансы WalletConnect, включая ключи сеансов |
| `data/exchange-history.json` | Обмены и депозиты Best Rate |
| `data/revoke-history.json` | Отзывы разрешений |
| `data/jumper-storage.json` | Настройки Jumper |
| `Logs/coinman-ГГГГ-ММ-ДД.log` | Ежедневные логи, если включён Debug mode |

Хранилище браузера окна (cookies, local storage) временное и удаляется при
обычном закрытии программы. Всё, что должно пережить перезапуск, хранится в
файлах выше.

## Резервные копии

Чтобы сделать копию, закройте программу и скопируйте папку `data`. Чтобы
перейти на другой компьютер, перенесите программу вместе с папкой `data`.

Зашифровать можно только базу портфелей (см.
[Файлы баз и шифрование](05-databases-and-encryption.md)). Остальные файлы
хранятся как есть — особенно `wallets.json` и `settings.json` никому не
передавайте.

## Логи

По умолчанию логи выключены. Включите их пунктом **Settings → Debug mode
(write log files)**; **Settings → Open logs folder** открывает папку.

Запуск программы с `--debug` включает логи и инструменты разработчика
(правая кнопка → Inspect) только на этот запуск:

```
coinman-portfolio --debug
```

Логи помогают найти причину проблемы. В них могут быть адреса кошельков и
подробности транзакций; просмотрите лог, прежде чем кому-то его отправить.
