# Установка

Скачайте файл для своей системы со страницы
[GitHub Releases](https://github.com/coinman-dev/portfolio/releases).
Версии с `-beta` в названии — тестовые: перед обновлением сделайте копию базы
(см. [Файлы, папки и логи](13-files-and-logs.md)).

| Система | Файл |
|---|---|
| Windows 10/11 x64 | `coinman-portfolio-windows-x64.zip` |
| Linux x64 (Ubuntu 22.04 и новее) | `coinman-portfolio-linux-x64.tar.gz` |
| macOS, Intel | `coinman-portfolio-macos-x86_64.dmg` |
| macOS, Apple Silicon (M1 и новее) | `coinman-portfolio-macos-aarch64.dmg` |

## Windows

1. Распакуйте zip в папку, куда у вас есть право записи, например
   `D:\CoinMan`. Не в `C:\Program Files`: программа хранит данные рядом с
   `coinman-portfolio.exe`.
2. Запустите `coinman-portfolio.exe`.

Программа не подписана. Если SmartScreen пишет «Windows защитила ваш
компьютер», нажмите **Подробнее → Выполнить в любом случае**.

## Linux

1. Установите WebKitGTK, если его ещё нет:
   `sudo apt install libwebkit2gtk-4.1-0`.
2. Распакуйте архив в папку, куда у вас есть право записи:
   `tar -xzf coinman-portfolio-linux-x64.tar.gz -C ~/CoinMan`.
3. Запустите `~/CoinMan/coinman-portfolio`.

Программа работает в сеансах X11 и Wayland.

## macOS

Откройте `.dmg` и перетащите программу в **Программы** или любую другую
папку. Программа не подписана: при первом запуске нажмите на неё правой
кнопкой, выберите **Открыть** и подтвердите.

## Только одна копия

Одновременно работает одна копия программы. Повторный запуск выводит на
передний план уже открытое окно.

## Обновление

Раз в неделю, через несколько секунд после запуска, программа проверяет на
GitHub, вышла ли новая версия. Если вышла, справа в строке состояния
появляется **Update available**; нажмите, чтобы открыть страницу релиза.

Чтобы обновиться, замените исполняемый файл (`coinman-portfolio.exe` или
`coinman-portfolio`) новым, а папку `data` рядом с ним оставьте.

## Удаление

Закройте программу и удалите её папку. Все данные — базы, настройки,
сохранённые кошельки, истории и логи — лежат в этой папке (`data` и `Logs`),
так что после удаления ничего не остаётся.
