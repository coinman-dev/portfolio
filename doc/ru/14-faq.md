# Решение проблем и вопросы

## Цены не загружаются

Посмотрите на **Market data** в строке состояния. Если там ошибка:

- проверьте подключение к интернету;
- CoinGecko ограничивает частоту запросов; подождите минуту;
- с CoinMarketCap проверьте ключ (**Settings → Fetch prices from
  CoinMarketCap**). Если ключ не работает, программа берёт цены из CoinGecko.

Монета без цены считается по цене покупки.

## Забыл пароль от базы

Без него базу не расшифровать — восстановления нет. Восстановите резервную
копию папки `data/base`, если она есть.

## Программа не запускается в Linux

Установите WebKitGTK: `sudo apt install libwebkit2gtk-4.1-0`. Запустите
программу из терминала, чтобы увидеть сообщение об ошибке.

## Windows или macOS не дают запустить программу

Программа не подписана. Windows: **Подробнее → Выполнить в любом случае**.
macOS: правая кнопка на программе → **Открыть**.

## Вторая копия не открывается

Одновременно работает одна копия; повторный запуск выводит на передний план
уже открытое окно. Если окна не видно, найдите его на панели задач.

## Хранилища Yearn всё время загружаются

Список хранилищ приходит с серверов Yearn (Kong и yDaemon). Если один из них
не отвечает, список остаётся на заглушках загрузки. Попробуйте позже;
yearn.fi в браузере в это время обычно тоже не работает.

## Best Rate не показывает маршрутов

- Проверьте сумму: слишком маленькую многие сервисы не берут из-за комиссий,
  слишком большая может не поместиться в пулы.
- Откройте **Нет маршрута у N сервисов** внизу — каждый сервис пишет, почему
  у него ничего нет.
- Посмотрите **Выше вашего лимита комиссии N%** под маршрутами и список
  сервисов в **⚙**: сервисы без галочки не опрашиваются.

## Кнопка «Депозит» неактивна

Сначала введите адрес получения: memo депозита должно содержать адрес, на
который придут монеты.

## Где ключи от моего кошелька?

В вашем кошельке. CoinMan хранит только сеансы WalletConnect
(`data/wallets.json`) и просит кошелёк подписать; каждая транзакция
подтверждается в кошельке.

## Как перейти на другой компьютер?

Скопируйте папку программы вместе с `data`. Сохранённые сеансы WalletConnect
на новом компьютере, возможно, придётся подключить заново.

## Куда сообщить о проблеме?

На GitHub: [github.com/coinman-dev/portfolio/issues](https://github.com/coinman-dev/portfolio/issues).
Включите **Debug mode**, повторите проблему и приложите лог — убрав из него
адреса и всё личное.
